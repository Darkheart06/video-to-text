РАСШИФРОВКА ЗАПИСЕЙ
Транскрипт, саммари и бриф из аудио и видео — целиком на вашем компьютере.


КАК УСТАНОВИТЬ

Нажмите на «Установить Расшифровку» правой кнопкой мыши и выберите «Открыть».
Дальше — кнопка «Установить» и минут десять ожидания.

Именно правой кнопкой, а не двойным щелчком: программа собрана без платной
подписи Apple, поэтому при обычном запуске macOS откажется её открывать.
Через «Открыть» в контекстном меню появится та же самая проверка, но с кнопкой,
которая разрешает запуск. Это нужно сделать один раз.

Установщику нужен интернет: он скачивает около полутора гигабайт — Python,
ffmpeg и модели для распознавания. Компьютер в это время можно не трогать.


ЧТО ПОЯВИТСЯ ПОСЛЕ УСТАНОВКИ

Приложение «Расшифровка» в папке «Программы». Перетащите в его окно запись
(mp4, mov, webm, mp3, m4a, wav) — и получите транскрипт с таймкодами,
разделение по спикерам, саммари, бриф, список задач и решений.

Готовые файлы складываются в папку «Расшифровка записей» в ваших документах.


ЕЩЁ ОДИН ШАГ — ЯЗЫКОВАЯ МОДЕЛЬ

Транскрипт приложение делает само. Для саммари нужна языковая модель;
установщик предложит скачать Ollama — это самый простой путь:

    ollama pull gemma4:12b-mlx

В настройках приложения можно вместо Ollama указать файл модели .gguf
на диске или адрес своего сервера с OpenAI API.


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

Ход установки записывается в файл:
    ~/Library/Logs/Расшифровка-установка.log

Ничего из ваших записей никуда не отправляется: распознавание, разделение
по спикерам и саммари считаются на вашем компьютере.
